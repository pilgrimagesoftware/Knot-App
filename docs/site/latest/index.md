# Knot documentation

Knot is a desktop workspace that runs a team of AI coding agents, each in its
own terminal or conversation panel, and lets them coordinate through a local
MCP server. This is the latest documentation.

## Getting started

- [Installation]({{ '/latest/install/' | relative_url }}) - download or build Knot, and the macOS quarantine and signing notes.
- [Workspaces]({{ '/latest/workspaces/' | relative_url }}) - create a workspace, open its window, and use the dashboard and Command Center.
- [Agents]({{ '/latest/agents/' | relative_url }}) - add an agent, pick a type, and work with its lifecycle, status, and conversation panel.

## Using Knot

- [Coordination]({{ '/latest/coordination/' | relative_url }}) - how agents register, message one another, plan tasks, and use the MCP tool catalog.
- [Git and worktrees]({{ '/latest/git-worktrees/' | relative_url }}) - review and commit an agent's changes, create worktrees, and track pull requests.
- [Settings]({{ '/latest/settings/' | relative_url }}) - the settings window, appearance, notifications, import, and the app's other windows.
- [Personas and prompts]({{ '/latest/personas-prompts/' | relative_url }}) - persona and prompt libraries, startup prompts, and prompt variables.
